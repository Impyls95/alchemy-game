# ⚗️ Алхимия / Alchemy

Браузерная головоломка о смешивании элементов: перетаскивай **Воду** на **Огонь** — получай **Пар**, открывай новые элементы и строй цепочки от четырёх стихий до жизни, городов и интернета.

**Играть онлайн:** https://Impyls95.github.io/alchemy-game/

- **133 рецепта, 130 элементов** — все достижимы от базовых (валидация при загрузке).
- Полностью клиентская игра: чистый HTML + CSS + JS (ES-модули), без сборки, без зависимостей, без рекламы и трекеров.
- Drag & drop на Pointer Events: мышь и тач (на телефоне: тап по элементу — добавить на поле, удержание — перетащить, свайп — прокрутка палитры).
- Прогресс, позиции плиток и настройки сохраняются в `localStorage`; на платформе Яндекс Игр — в прогрессе игрока (`player.setData`) с локальной копией как резервом.
- Русский / English, тёмная и светлая темы, синтезированные звуки (можно отключить), подсказки с кулдауном, поиск и сортировка по палитре, бейджи NEW.
- Ранги алхимика в шапке (🎓 Ученик → 👑 Архимаг) и панель достижений (🏆 — 8 значков: от «Первого творения» до «Великого алхимика»).
- Перенос прогресса между устройствами без регистрации: ❓ → «Перенос прогресса» — скопируйте код сохранения и вставьте его на другом устройстве.
- Книга рецептов всех открытых сочетаний (📖), undo последнего слияния («Вернуть» в тосте после крафта), шаринг прогресса (📤).

## Запуск локально

Вариант 1 — просто открыть `index.html` в браузере. Игра работает и по `file://`: если `fetch` до `data/recipes.json` недоступен, используется встроенная копия рецептов (`js/recipes-fallback.js`).

Вариант 2 — любой статический сервер (рекомендуется):

```bash
npx serve .
# или
npx http-server -p 8080 .
# или
python -m http.server 8080
```

Откройте `http://localhost:8080` (или порт, который покажет serve).

## Структура проекта

```
index.html            разметка: поле, палитра, шапка, модалки
css/styles.css        темы, плитки, анимации, адаптив
js/main.js            точка входа: состояние, палитра, UI, сохранение
js/game.js            поле, drag & drop, слияние, эффекты, звук
js/recipes.js         загрузка и валидация рецептов (симметрия пар, достижимость)
js/recipes-fallback.js встроенная копия рецептов для запуска без сервера
js/storage.js         хранилище прогресса: подключаемый backend, дебаунс записи
js/platform.js        адаптер платформ: веб / Яндекс Игры (SDK, player-сохранения)
js/elements.js        иконки (emoji) и английские имена элементов
js/i18n.js            словари RU/EN
data/recipes.json     рецепты — расширяются без изменения кода
```

## Как добавить рецепт

Допишите строку в `data/recipes.json`:

```json
{ "a": "Вода", "b": "Огонь", "result": "Пар" }
```

- Комбинация симметрична: порядок `a`/`b` не важен.
- Новый элемент подхватится автоматически: счётчик `N / M` пересчитается, для неизвестного имени будет fallback-иконка ✨. Чтобы задать иконку и английский перевод, добавьте запись в `js/elements.js`.
- При загрузке игра проверяет достижимость всех элементов от базовых и конфликтующие пары — предупреждения выводятся в консоль.
- После правки JSON обновите встроенную копию (нужна только для режима `file://`):

```bash
{ printf '// Автогенерация из data/recipes.json\nexport const FALLBACK_DATA = '; cat data/recipes.json; printf ';\n'; } > js/recipes-fallback.js
```

## Деплой

Игра — чистая статика, подойдёт любой хостинг.

### GitHub Pages

1. Запушьте репозиторий на GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Готово: `https://<user>.github.io/<repo>/`.

### Netlify

Перетащите папку проекта в [Netlify Drop](https://app.netlify.com/drop) или подключите репозиторий: build command — пусто, publish directory — `.`.

### Vercel

```bash
npx vercel --prod
```

Framework preset: `Other`, build command и output directory оставьте пустыми.

### Свой сервер (nginx)

Скопируйте файлы в `/var/www/alchemy` и добавьте серверный блок:

```nginx
server {
    listen 80;
    server_name alchemy.example.com;
    root /var/www/alchemy;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(json|js|css)$ {
        add_header Cache-Control "public, max-age=3600";
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### Яндекс Игры

Игра адаптирована под платформу: на хостинге Яндекса автоматически подгружается SDK (`/sdk.js`), прогресс сохраняется через `player.setData` (привязка к аккаунту игрока), стартовый язык берётся из окружения, а кнопка «Поделиться» скрывается (модерация запрещает внешние ссылки). Вне платформы ничего не меняется — SDK не загружается.

Локальная проверка платформенной ветки без SDK: откройте `http://localhost:8080/?mockysdk=1` — подставляется мок (`LoadingAPI.ready()`, player-сохранения в ключе `alchemy.mockysdk.player`, скрытая кнопка 📤).

Сборка zip для консоли (`index.html` в корне архива):

```bash
python -m zipfile -c dist/alchemy-yandex.zip index.html css js data
```

Публикация:

1. Зарегистрируйтесь в [Консоли разработчика Яндекс Игр](https://yandex.ru/games/console) и заполните профиль.
2. «Добавить игру» → черновик: загрузите zip, укажите название, описание, категорию и возрастной рейтинг (GRA).
3. Подготовьте материалы: иконка 512×512 (`dist/alchemy-icon-512.png`) и 2–3 скриншота геймплея (`dist/screenshots/`).
4. Отправьте на модерацию — игра появится в каталоге после проверки (обычно несколько дней).

Требования платформы, которые уже соблюдены: SDK встроен и вызывает `LoadingAPI.ready()`, игра работает в iframe, внешние запросы отсутствуют, все ресурсы локальные, RU/EN локализация.

### Пикабу Игры

[Пикабу Игры](https://games.pikabu.ru/add-own-game) принимает уже размещённую HTML5-игру по ссылке — после пуша на GitHub Pages можно отправить URL каталога напрямую.

## Управление

| Действие | Десктоп | Мобильный |
|---|---|---|
| Добавить элемент на поле | перетащить из палитры или клик | тап по элементу или удержание + перетаскивание |
| Смешать | перетащить плитку на плитку или тап по плитке → тап по второй | то же |
| Убрать плитку | перетащить в палитру или двойной клик | перетащить в палитру |
| Очистить поле | кнопка 🧹 | кнопка 🧹 |
| Подсказка | 💡 (кулдаун 45 с) | 💡 |
| Книга рецептов | кнопка 📖 | кнопка 📖 |
| Достижения | кнопка 🏆 | кнопка 🏆 |
| Перенести прогресс | ❓ → блок «Перенос прогресса» | то же |
| Вернуть последнее слияние | «Вернуть» в тосте после крафта | то же |
| Поделиться прогрессом | кнопка 📤 | кнопка 📤 |
| Сброс прогресса | 🗑️ с подтверждением | 🗑️ с подтверждением |

Поддерживаются Chrome, Firefox, Safari и мобильные браузеры (нужны ES2022-модули, Pointer Events, `localStorage`).
